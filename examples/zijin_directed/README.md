# 紫禁·借势归锋

这是 Codex 辅助编导提供的三镜动作稿，不是自动分镜成功案例。用于在自动创作不稳定时，以明确署名的创作输入完成真实影片；原先失败工作区不变。

- 0–5 秒：玄衣剑客轻功上檐；白衣剑客斜劈，玄衣剑客避锋并顺势拨开回剑。
- 5–10 秒：白衣回斩；玄衣贴身闪入、旋剑上引，再连续变招下扫，迫使白衣提膝失衡。
- 10–15 秒：白衣孤注一掷下斩；玄衣错身回刺，白衣非血腥地中剑倒下，玄衣收剑，结局持续可见。

相机保持同一侧轴线：抬升呈现入场、短距离横移跟住交锋、小幅后拉呈现胜负。两段切点保留未完成剑势，不重置人物位置。时间由正式编译器计算，实际可见动作仍须由视频验收确认。

准备并检查（默认视频预算为零；这里只调用文本审稿，尚不生成视频）：

```bash
python -m tools.prepare_authored_run examples/zijin_directed/authoring.json
python main.py --resume <返回的工作区> --plan-only
```

`authored_input.json` 保存完整输入，`authorship.json` 保存署名与源内容指纹。导入不替代独立语义审查；正式恢复仍通过相同的生成、连续性、质量与拼接流程。授权视频预算后准备的工作区才可进入付费生成。
